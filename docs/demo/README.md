# Demo assets

Add a before/after clip here for the portfolio README.

## Suggested demo

1. Record or download a 30–60s horizontal talking-head clip (podcast snippet, vlog, etc.).
2. Run:
   ```bash
   python pipeline.py samples/before.mp4 --short -o docs/demo/after.mp4
   ```
3. Embed `after.mp4` in the root README under the Demo section.

A side-by-side GIF or two static screenshots (before crop / after crop) also works if you do not want to commit video files to git.
